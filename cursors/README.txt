Cursors for the preview of 扫图裁切.

default, grab, grabbing, crosshair, ew-resize, ns-resize, nesw-resize and
nwse-resize are unmodified sources from mocu-xcursor by sevmeyer,
https://github.com/sevmeyer/mocu-xcursor, released under CC0 1.0
(see LICENSE-mocu.txt). rotate.svg is drawn for this tool in the same format
and proportions.

The files keep mocu's placeholder colours (#fafbfc fill, #1a1b1c outline,
#0a0b0c shadow) and its hotspot marker (circle id="hot"); scan_cropper_cursors
applies the theme colours and reads the hotspot when rendering. If this folder
is removed, the preview falls back to the system cursors.
