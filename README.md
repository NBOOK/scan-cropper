# 扫图裁切

批量整理书刊扫描图的桌面工具：自动检测纸边、纠正倾斜，为整批页面推荐统一的裁切尺寸，再逐页检查和微调后导出。

## 功能

- 自动检测纸边，适用于深色、浅灰或白色的扫描背景
- 纠正倾斜，整批统一输出尺寸，按左右页的装订内侧分别定位
- 支持拆开的单页，也支持未拆书扫描（内侧连着另一半书页）
- 自动推荐梯形与斜切校正
- 逐页微调：数值输入、鼠标拖动、按参考线校正角度，可撤销
- RGB 通道对齐，减轻彩色扫描的彩边和重影
- 保存批次配置，之后继续调整
- 预览与导出结果逐像素一致；原图不会被修改

## 安装与启动

需要 Python 3.10 或更新版本。

```bash
pip install -r requirements.txt
python scan_cropper_gui.py
```

Windows 下环境变量里有python时也可以双击 `start_scan_cropper_gui.bat` 启动。

## 快速上手

1. 在“扫描原图”中选择或拖入这一批图片所在的文件夹，“输出目录”默认为其中的 `cropped` 子文件夹，也可以另选。支持 PNG、JPEG、TIFF、BMP 和 WebP，按文件名自然顺序排列。
2. 设置“内侧在左”或“内侧在右”。内侧指靠书脊、装订的一侧。左右页轮换时勾选“交替”，所选方向对应第一张参与分析的图。
3. 勾选“自动裁切”；需要纠正梯形或斜切变形时，同时勾选“自动梯形校正”。
4. 封面、封底等不适合参与整批统计的页，填入“排除分析页码”，如 `1,2`。
5. 点击“分析文件夹”。
6. 逐页检查：先用整批裁量处理共同问题，再调整个别页的角度和位置。
7. 点击“导出全部裁切图”。

导出沿用原文件名；输出目录不能与原图目录相同，已有同名文件时会询问是否覆盖。

## 按扫描方式设置

### 拆开的单页

不勾选“指定宽度”。程序分析整批页面，推荐统一的输出宽高，并为每页计算角度和裁切位置。

### 未拆书扫描

内侧连着另一半书页、没有清晰纸边时，勾选“指定宽度”。“内侧裁掉”会变为“图像宽度”，填入期望的输出宽度（原图像素）。程序以外侧纸边和上下纸边定位，从外侧向内取指定宽度，不把另一半书页或书脊当作边界。

### 排除的页

“排除分析页码”可填单页和范围，如 `1,2,5-8`，按文件排序从 1 开始计数，与文件名中的数字无关。

排除的页不参与整批尺寸统计，也不计入左右交替，但仍会套用整批尺寸并一起导出：

- 只扫了跨页一半、内侧超出扫描范围的封面封底：按外侧和上下纸边定位；
- 两侧纸边都可见的页：按检测到的纸张居中；
- 检测不到纸边时：放在图片中央，需要手动调整。

修改处理模式、分析开关或排除页码后，需要重新点击“分析文件夹”才会生效；在此之前当前结果保持不变。

## 调整裁切

### 整批裁量

“顶部裁掉”“底部裁掉”“外侧裁掉”“内侧裁掉”是在自动结果上追加的裁量，单位为原图像素：0 为自动结果，正数向内多裁，负数向外多留。内外侧随每页的装订方向对应。

### 当前页

| 控件         | 作用                                       |
| ------------ | ------------------------------------------ |
| 旋转角度     | 本页角度，正数为顺时针                     |
| 参考线       | 在图上点两点，把这条线校正为水平或竖直     |
| 偏移 X / Y   | 在自动位置上移动裁切框；X 向右、Y 向上为正 |
| 增量 宽 / 高 | 只改变本页的输出尺寸                       |
| 本页梯形校正 | 开关本页的梯形校正，并可调整四角           |
| 重置本页微调 | 恢复本页的自动结果                         |
| 重新分析本页 | 某页重扫替换原图后，只重新检测这一页       |

“本页输出”显示本页最终导出的尺寸。

### 鼠标操作

按住 **Ctrl** 时，光标会随位置变化：

| 位置       | 拖动效果                             |
| ---------- | ------------------------------------ |
| 裁切框的边 | 移动这条边，改变本页尺寸             |
| 裁切框的角 | 单独移动这个角，形成梯形或四边形裁切 |
| 裁切框内   | 移动整个裁切框                       |
| 裁切框外   | 绕页面中心旋转，松开后应用           |

不按 Ctrl 时，拖动用于平移视图，滚轮缩放。

### 参考线

点击“参考线”或按 **Ctrl+R**，然后按住 Ctrl 在图上依次点击两点，比如一条分镜框线或文字行的两端。程序判断这条线更接近水平还是竖直，并据此调整本页角度。按 Esc 取消。

### 梯形与斜切校正

勾选“自动梯形校正”后，程序会区分整体变形与纸边的局部弯曲，只在证据充分时推荐校正；某条边不可靠时，可能只按其余三条边推荐斜切校正。

预览显示的是校正前的图像，黄色四边形表示取图范围，导出时才拉成矩形。只拖角不会改变输出尺寸，需要时请调整本页宽高增量。

## 检查与快捷键

**空格**在完整图像和只显示裁切结果之间切换。“视图”菜单可更换预览背景色，或显示检测到的纸边（青色）。

| 按键                     | 功能                    |
| ------------------------ | ----------------------- |
| Q / E，PageUp / PageDown | 上一页 / 下一页         |
| W / A / X / D，方向键    | 裁切框移动 1 px         |
| 空格                     | 切换完整图像 / 裁切结果 |
| Ctrl+Z / Ctrl+Shift+Z    | 撤销 / 重做             |
| Ctrl+R                   | 参考线                  |

**快速定位**：按住 Shift 加下列按键，把裁切框的角或边中点移到视图中央并放大；再按一次同一组键回到原来的视角。

|           |             |           |
| --------- | ----------- | --------- |
| Q：左上角 | W：上边     | E：右上角 |
| A：左边   | S：完整图像 | D：右边   |
| Z：左下角 | X：下边     | C：右下角 |

**扫边检查**：按住 Alt+W / A / X / D 沿上、左、下、右边自动平移查看；Alt+S 依次扫完四条边。松开即回到原视角。速度和放大倍率在“视图 → 扫边与定位设置…”中调整。

## 颜色校正

彩色扫描时，扫描仪的红、绿、蓝通道可能有亚像素错位，表现为彩边和重影。颜色校正按一组偏移参数把三个通道对齐，不改变白平衡和色调。

偏移参数取决于扫描设备和扫描设置，不同设备之间不能通用，用错会产生新的彩边。首次使用时先标定：

1. 载入一批图片，选择“颜色校正 → 按页码范围共同标定 RGB 偏移…”。
2. 填入用于测量的页码，留空表示全部。最好选用彩色模式扫描的黑白或灰度内容页，如黑白漫画或文字页。
3. 测量完成后，点击“写入当前 Profile，应用整批”。

之后同一设备、同一设置的扫描可直接选用这个 Profile。不确定参数是否适用时，可以在“颜色校正”菜单中开关比较效果。灰度图片不受影响。

## 保存、重新分析与导出

**保存进度**：点击“导出批次配置…”保存这一批的整批裁量和每页的角度、偏移、尺寸及梯形参数，之后用“批次 → 导入批次配置…”恢复，需要原图仍在原处。软件会自动记住目录和各项选项，但不会保存逐页调整，需要继续调整时请保存批次配置。

**重新计算**：“批次 → 按当前设置重新计算未排除页”按当前整批裁量重新推荐各页的角度和位置，会覆盖这些页的微调。

**导出**：“导出全部裁切图”导出所有页；“导出指定页码…”只导出选定的页，如 `1,3,5-8`。

## 扫描建议

- 让纸边与扫描背景有清晰的明暗差别，四周留出一点可见的背景，不要让纸边距离扫描边缘过近。
- 同一批请使用相同的扫描分辨率（DPI）；图片本身的尺寸可以不同。
- 页面不必摆得很正，倾斜会自动纠正。
- 梯形校正只处理整体形状，无法展平书脊附近的隆起或非线性形变。

## 其他扫描仪

默认的检测是通用的，只要求纸张与扫描背景有亮度差别。

`scan_cropper_adapters.py` 包含为作者所用扫描仪编写的附加处理：扫描仪顶部的亮边与暗槽、未拆书扫描时的顶部标尺，以及纸边被与背景同样暗的深色印刷遮住时的识别。它们可能不适合你的扫描仪或摆放方式。如果纸边检测或角度不准，可以删除这个文件，软件会回到通用检测，其他功能不受影响。
